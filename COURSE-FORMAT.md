# Формат файла курса (.md)

Трекер читает markdown в стиле `courses-v2`: YAML-подобный frontmatter, заголовок курса, модули и куски (pieces).

## Пример

```markdown
---
color: "#5B8DEF"
image: "images/cursor.svg"
---
# Cursor — мастерская

Краткое описание курса (необязательно).

## CUR-1 · Get Started — старт

### CUR-1.1 · Интерфейс и проект
- **Цель:** Открыть проект и понять, где что.
- **Делаю:** …

### CUR-1.2 · Модели ✅
- **Статус:** ✅ пройдено
- **Цель:** …
```

## Поля

| Часть | Правило |
|--------|---------|
| **Frontmatter** | Между `---`: `color` (hex), `image` (путь `images/…`, URL, `data:` или inline SVG). |
| **Название** | Первая строка `# Заголовок`. |
| **Модуль** | `## <ID> · <название>` — без `·` и ID секция игнорируется (например «Пройдено»). |
| **Кусок** | `### <ID> · <название>`; цель — строка `- **Цель:** …`. |
| **Пройдено** | Кусок считается выполненным изначально, если ✅ в заголовке, в `- **Статус:**`, или ID перечислен в секции `## Пройдено` как `- **CLA-1.3** · … ✅`. |

`image` при импорте может быть URL, `data:` URI, фрагмент `<svg>…</svg>` или путь к файлу в bundle.
