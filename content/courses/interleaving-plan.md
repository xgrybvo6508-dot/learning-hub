# Interleaving-план: 2 недели (9–22 октября 2026)

Курсы: [[discrete-math/00-overview|Дискретка]] · [[learning-science/00-overview|Learning Science]] · дриллы: [[mindmapping-drills]]

## Коды
- Задачи: `DM2.3` = модуль 02 дискретки, задача 3; `LS4.2` = модуль 04 learning science, задача 2.
- Тип задачи дискретки (для чередования): **[P]** доказательство/инвариант · **[C]** подсчёт · **[R]** рекуррентность/ПФ · **[G]** графы.
- `Dn` = дрилл n из [[mindmapping-drills]]; «модульный дрилл» = майндмэп-дрилл внутри файла модуля.
- 🔥 ignition — 5 минут на самую интересную задачу, только попытка (запуск через интерес/вызов).

## Правила (ADHD-friendly)
1. **If–then запуск:** «Если [моё время] и я сел за стол → открываю этот файл, ставлю визуальный таймер на первый блок». Телефон — в другой комнате.
2. **Блоки 5–25 мин**, перерыв 5 мин с движением после ~40 мин работы. Гиперфокус на задаче из плана — можно продолжить, но якорь «вода/еда» через 60–90 мин.
3. **В смешанных наборах** перед каждой задачей 10 сек: *назови метод и почему* (это и есть тренировка различения). Порядок задач — как в плане, не сортировать по модулям.
4. **Решение смотреть** только после ≥10 мин честной попытки; уверенность 1–5 ставить *до* проверки.
5. **Anki ежедневно** (5–10 мин): обе колоды, лимит новых 10/день на колоду. Каждая ошибка дня → 1 своя карточка *why/contrast*.
6. **MVD** (день без сил): 1 задача 10 мин + 5 Anki + 1 строка в Obsidian. Засчитывается.
7. **Пропуск дня:** не сжимать два дня в один — сдвинуть план на день, но **оставить перерисовки** (они привязаны к интервалу 1–3 дня).
8. **Переключение между курсами** — с ритуалом 30 сек: записать, где остановился → встать → следующий блок.
9. Каждый вечер: 1 инсайт в Obsidian с тегом `#insight/learning` или `#insight/dm`.
