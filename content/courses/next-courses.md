# Следующие курсы — только списки модулей

Формат тот же: `00-overview` с картой-скелетом, модули «идеи как связи + майндмэп-дрилл + hard-задачи + Фейнман + Anki», общий [[interleaving-plan]]. Источник целей — карта «Система обучения» (нейропсихология: анализ данных, новые подходы, коммуникация + ИИ; английский).

## 3. Нейропсихология и коммуникация с ИИ
1. **Мозг как система предсказаний** — predictive processing, внимание, дофамин и ожидание награды (связь с [[06-adhd-friendly-practice]]).
2. **Исполнительные функции и их измерение** — модели (Miyake, Barkley), тесты (Stroop, n-back, WCST), что они реально меряют.
3. **Нейроразнообразие без мифов** — РАС, СДВГ, 2e: монотропизм, двойная эмпатическая проблема (Milton), сильные стороны, доказательность.
4. **Анализ данных в нейро/психо-исследованиях** — дизайн экспериментов, размер эффекта, p-hacking, кризис воспроизводимости, базовый Python/pandas на открытых датасетах (OpenNeuro, OSF).
5. **Коммуникация: модели** — теория разума, прагматика (Грайс), транзактный анализ как рамка (и её ограничения), невербальное.
6. **ИИ как собеседник** — как LLM «понимают» (и нет), промпт как коммуникация, антропоморфизация, ИИ для тренировки разговоров и социальных сценариев.
7. **Проект** — мини-исследование: собрать свои данные (сон/энергия/фокус из Daily Tracker) → анализ → выводы → карта.

## 4. English (для работы и информационной среды)
1. **Диагностика и цель** — уровень по CEFR, целевые ситуации (тех. чтение, созвоны, переписка, X/LinkedIn).
2. **Чтение тех. и научных текстов** — skim/scan, структура статьи, словарь по частотности (AWL), карты статей вместо перевода.
3. **Лексика через связи** — словообразование, коллокации, семьи слов; Anki *contrast/link*-карточки (не «слово → перевод»).
4. **Грамматика как система** — время/аспект как сеть, артикли, условные; карта вместо таблиц.
5. **Listening & shadowing** — подкасты/YouTube (Sung, лекции MIT), транскрипт → shadowing → пересказ голосом ИИ.
6. **Speaking с ИИ** — голосовые ролевые сценарии (интервью, созвон с командой), разбор ошибок, Фейнман на английском.
7. **Writing для карьеры** — профиль, cold-сообщения, README, посты; правка ИИ *после* своего черновика.
8. **Интеграция** — вести один из курсов (например, нейропсихологию) на английском.
