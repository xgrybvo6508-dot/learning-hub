# Claude — партнёр для мышления
Опора: курсы Claude Academy (academy.claude.com) + локальные модули claude-course (M0–M6). Один модуль = одна тема, источник указан у каждого.
Каждый кусок ~15 мин, независимый. Конец куска — мини-карта. Порядок выбираешь сам.

**Статус кусков.** ✅ пройдено · 🟡 в процессе · ⬜ не начато. Сверка с Claude Academy: 2026-10-12.

**Заметка.** В Academy есть ещё курсы, которых нет в этом файле: *AI-native SDLC playbook* (13/14) и *Building effective human-agent teams* (3/6). *Claude with Vertex AI* (9/75) параллелит темы CLA-4; основные источники CLA-4 (*Building with the Claude API*, *Claude Platform 101*) не начаты.
